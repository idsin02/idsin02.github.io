# Active Directory Detection Lab

This lab contains 24 client-free KQL hunting use cases and deterministic synthetic telemetry. The private report used as a defensive reference is not included, quoted, or identified in this public bundle. No production client names, domains, hosts, accounts, IP addresses, findings, or branding are present.

The browser simulation does not connect to a tenant. Adapt table names, field mappings, thresholds, allow-lists, and retention windows before production use.
