01 — operator profile

Security research, grounded in practice.

I'm Dhruv Singh, a threat hunter based in Pune, India, publishing security work as DHRUxMAN. I work in Cyber Threat Intelligence & Hunting at Tata Consultancy Services. There I turn threat intelligence into hunts, run dark web and digital risk monitoring, and build hypothesis-driven hunts across endpoint, identity, network, and cloud telemetry.

I start with the adversary. I break down the vulnerability or TTP, engineer the detection, then validate it against real telemetry. I maintain multi-format detection content for actively exploited CVEs and hunt across Sysmon, Microsoft Sentinel, Defender XDR (KQL), and CrowdStrike Falcon (CQL).

Before this, I completed a VAPT internship at Qseap Infotech and was acknowledged in NASA's Hall of Fame on Bugcrowd for responsible disclosure. My research and tooling are public, so you can check them yourself.

03 — detection engineering

Detection content I maintain.

My Queries-and-Detection-rules repository is a library of detection & triage packages for actively exploited vulnerabilities. Each package follows the same defensive pipeline and ships content in multiple formats so it works across the tools teams actually run.

Package design: every CVE package is organized as a hunt pipeline, not a single rule —
exposure inventory→ edge / waf→ server logs→ execution→ post-exploitation→ ioc sweep

PHP2Shell — CVE-2026-109618 / CVE-2026-109619 CVSS 9.8 · CRITICAL

Unauthenticated RCE in the PHP core Zend Engine (use-after-free via malformed serialize() input), exploitable under default Apache mod_php across PHP 5.4–8.5.11. Detection content targets webserver file drops, shell spawns from PHP workers, environment-variable exfiltration markers, OOM crash bursts, and campaign IOCs.

07 — temp.hex

    
temp.hex — adversary emulation, end to end.

    
temp.hex is my threat hunting lab: a controlled, staged emulation of the tradecraft associated with TEMP.Hex — a China-nexus espionage actor also tracked as Sogu, known for USB-borne entry into air-gapped and isolated networks. Rather than reading about the actor, I rebuilt its attack chain in a lab, captured the telemetry, and wrote the hunts.

    

      
STAGE 1
USB Execution
A weaponized USB drops a RECYCLER.BIN payload; execution fires on insertion — the actor's signature entry vector.
T1091 · Replication via Removable Media

      
STAGE 2
Discovery & Staging
Host and network reconnaissance, staging collected data for exfiltration.
Discovery tactics

      
STAGE 3
C2 Beaconing
Periodic command-and-control callbacks simulating the actor's beacon pattern.
Command & Control

      
STAGE 4
Registry Persistence
Survival across reboots via registry modification.
Persistence · T1547

      
STAGE 5
Obfuscation & Decode
A Base64 payload hides in config.dat; decoder.ps1 reconstructs and executes it — validating visibility into runtime decoding.
T1027 · T1140 · T1059.001
