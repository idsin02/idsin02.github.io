Week 9 · Day 2

KQL behavior query + tuning

Page 3 / 8

What should be done

  1. Start with the normalized TaskTelemetry_CL table.
  2. Combine command and path into lowercase text.
  3. Find risky folders or interpreter names.
  4. Remove only the exact approved Firefox maintenance tuple.
  5. Project fields needed for triage.

Why the tuning is narrow

An interpreter is not automatically malicious. The example exclusion requires the approved task name, publisher, path, and expected maintenance command together. A change in any one value remains visible.

Replace the sample custom-table and field names with your connector's mapping, then validate against one known event.

KQL answer

Validation place: Microsoft Sentinel or Defender after mapping task and process telemetry into the listed fields.

TaskTelemetry_CL
| where EventType_s in~ ("task_created", "process_start")
| extend SearchText = tolower(strcat(Command_s, " ", Path_s))
| extend Program = tolower(extract(@"([^\\\s\"]+\.exe)", 1, Command_s))
| extend RiskyFolder = SearchText contains @"\appdata\"
    or SearchText contains @"\temp\"
    or SearchText contains @"\downloads\"
| extend Interpreter = Program in~
    ("powershell.exe", "pwsh.exe", "cmd.exe", "wscript.exe", "cscript.exe", "mshta.exe")
| where RiskyFolder or Interpreter
| where not(
    TaskName_s =~ @"\Mozilla\Firefox Default Browser Agent"
    and Publisher_s =~ "Mozilla Corporation"
    and Path_s =~ @"C:\Windows\System32\cmd.exe"
    and Command_s contains @"\Program Files\Mozilla Firefox\default-browser-agent.exe"
)
| project TimeGenerated, Device_s, EventType_s, TaskName_s,
          Command_s, Actor_s, Path_s, Parent_s, Publisher_s,
          RiskyFolder, Interpreter
| order by TimeGenerated desc

Analyst reasoning

Likely false positives: software updaters, browser maintenance tasks, and enterprise management tools. Confirm the signer or publisher, install path, task owner, trigger, approved task name, command line, affected devices, and change ticket before adding an exclusion.

Analyst reasoning

Week 9 · Day 5

Normalize actions with Python

Page 6 / 8

What should be done

Save the Day 1 lines as task_events.jsonl. The program joins command and path into one normalized action, then lists the reason that action is risky.

Easy reading plan

  1. Open the JSONL file.
  2. Lowercase and normalize slashes.
  3. Look for three user-writable folders.
  4. Look for six interpreters.
  5. Skip one exact approved browser task.

Python answer

import json

RISKY_FOLDERS = ("\\appdata\\", "\\temp\\", "\\downloads\\")
INTERPRETERS = {
    "powershell.exe", "pwsh.exe", "cmd.exe",
    "wscript.exe", "cscript.exe", "mshta.exe",
}


def normalize_action(event):
    text = f'{event["command"]} {event["path"]}'
    return text.replace("/", "\\").lower()


def program_name(command):
    first = command.strip().strip('"').split()[0]
    return first.replace("/", "\\").split("\\")[-1].lower()


def approved(event):
    return (
        event["task_name"].lower() == "\\mozilla\\firefox default browser agent"
        and event["publisher"].lower() == "mozilla corporation"
        and event["path"].lower() == "c:\\windows\\system32\\cmd.exe"
        and "\\program files\\mozilla firefox\\default-browser-agent.exe"
        in event["command"].lower()
    )


def classify(event):
    if approved(event):
        return []
    action = normalize_action(event)
    reasons = []
    if any(folder in action for folder in RISKY_FOLDERS):
        reasons.append("user-writable folder")
    if program_name(event["command"]) in INTERPRETERS:
        reasons.append("script interpreter")
    return reasons


with open("task_events.jsonl", encoding="utf-8") as source:
    for line in source:
        event = json.loads(line)
        reasons = classify(event)
        if reasons:
            print(f'{event["event_number"]} {event["task_name"]} → {", ".join(reasons)}')

Go answer

package main

import (
    "bufio"
    "encoding/json"
    "fmt"
    "os"
    "strings"
)

type Event struct {
    TaskName  string `json:"task_name"`
    Command   string `json:"command"`
    Path      string `json:"path"`
    Publisher string `json:"publisher"`
}

func programName(command string) string {
    first := strings.Trim(strings.Fields(command)[0], `"`)
    parts := strings.Split(strings.ReplaceAll(first, `\`, `/`), "/")
    return strings.ToLower(parts[len(parts)-1])
}

func approved(e Event) bool {
    return strings.EqualFold(e.TaskName, `\Mozilla\Firefox Default Browser Agent`) &&
        strings.EqualFold(e.Publisher, "Mozilla Corporation") &&
        strings.EqualFold(e.Path, `C:\Windows\System32\cmd.exe`) &&
        strings.Contains(strings.ToLower(e.Command), `\program files\mozilla firefox\default-browser-agent.exe`)
}

func risky(e Event) bool {
    if approved(e) {
        return false
    }
    text := strings.ToLower(e.Command + " " + e.Path)
    folders := []string{`\appdata\`, `\temp\`, `\downloads\`}
    shells := map[string]bool{
        "powershell.exe": true, "pwsh.exe": true, "cmd.exe": true,
        "wscript.exe": true, "cscript.exe": true, "mshta.exe": true,
    }
    for _, folder := range folders {
        if strings.Contains(text, folder) {
            return true
        }
    }
    return shells[programName(e.Command)]
}

func main() {
    file, err := os.Open("task_events.jsonl")
    if err != nil {
        fmt.Println(err)
        return
    }
    defer file.Close()

    scanner := bufio.NewScanner(file)
    for scanner.Scan() {
        var event Event
        if json.Unmarshal(scanner.Bytes(), &event) == nil && risky(event) {
            fmt.Printf("%s → %s\n", event.TaskName, event.Command)
        }
    }
}

Analyst note

The program prints both creation and execution evidence, so a task may appear twice. That repetition is useful on Day 7: it shows the task was registered and later ran. Production code should also record JSON and scanner errors.
