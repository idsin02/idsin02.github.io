Week 13 · Day 2

KQL behavior query + tuning

Page 3 / 8

What should be done

  1. Start with normalized process-access telemetry.
  2. Keep lsass.exe targets.
  3. Use a bitwise test for risky rights.
  4. Suppress only approved signer + path pairs.
  5. Project the source image, mask, signer, hash, and device.

Why the tuning is narrow

A signer by itself is not enough: a legitimate utility can be copied to an unapproved location or abused. Each example suppression requires both the expected signer and the expected installation path.

Replace the teaching-table and field names only after checking one known event in your tenant.

KQL answer

let RiskyRights = tolong(122); // 0x007A: create-thread, VM operation/read/write, duplicate-handle
ProcessAccessEvents
| where TargetImage endswith @"\lsass.exe"
| extend AccessMaskLong = tolong(AccessMask)
| where binary_and(AccessMaskLong, RiskyRights) != 0
| where not(
    (Signer == "Microsoft Windows Publisher" and SourceImage startswith @"C:\Program Files\Windows Defender Advanced Threat Protection\")
    or (Signer == "CrowdStrike, Inc." and SourceImage startswith @"C:\Program Files\CrowdStrike\")
    or (Signer == "Microsoft Corporation" and SourceImage startswith @"C:\Program Files\Contoso\Diagnostics\")
    or (Signer == "Contoso Identity Security" and SourceImage startswith @"C:\Program Files\Contoso\CredentialProvider\")
)
| project Timestamp, Device, SourceImage, TargetImage,
          AccessMask, Signer, SHA256, SourceProcessId
| order by Timestamp desc

Analyst reasoning and false positives

Likely false positives: EDR/AV sensors, authorized crash-dump tools, approved diagnostics, and credential providers. Confirm product owner, signer, install path, hash or version, expected devices, and allowlist expiry. A new signer, a copied binary, or the same tool running from Downloads should remain visible.

Week 13 · Day 5

Python: decode rights and apply the allowlist

Page 6 / 8

What should be done

  1. Read one JSON object per line.
  2. Turn the mask string into a number.
  3. Convert set bits to friendly right names.
  4. Require the LSASS target and at least one risky right.
  5. Suppress only a matching signer + path prefix.

Expected output

1 → PROCESS_VM_READ
2 → PROCESS_CREATE_THREAD, PROCESS_VM_OPERATION, PROCESS_VM_READ, PROCESS_VM_WRITE
3 → PROCESS_DUP_HANDLE
4 → PROCESS_VM_READ
5 → PROCESS_VM_READ

Python answer

import json

RIGHTS = {
    0x0002: "PROCESS_CREATE_THREAD",
    0x0008: "PROCESS_VM_OPERATION",
    0x0010: "PROCESS_VM_READ",
    0x0020: "PROCESS_VM_WRITE",
    0x0040: "PROCESS_DUP_HANDLE",
}

APPROVED = [
    ("Microsoft Windows Publisher", "C:\\Program Files\\Windows Defender Advanced Threat Protection\\"),
    ("CrowdStrike, Inc.", "C:\\Program Files\\CrowdStrike\\"),
    ("Microsoft Corporation", "C:\\Program Files\\Contoso\\Diagnostics\\"),
    ("Contoso Identity Security", "C:\\Program Files\\Contoso\\CredentialProvider\\"),
]


def is_approved(event):
    signer = event["signer"].casefold()
    path = event["source_image"].casefold()
    return any(
        signer == good_signer.casefold() and path.startswith(good_path.casefold())
        for good_signer, good_path in APPROVED
    )


def right_labels(mask):
    return [name for bit, name in RIGHTS.items() if mask & bit]


with open("events.jsonl", encoding="utf-8") as file:
    for line in file:
        event = json.loads(line)
        mask = int(event["access_mask"], 0)
        labels = right_labels(mask)
        targets_lsass = event["target_image"].lower().endswith("\\lsass.exe")

        if targets_lsass and labels and not is_approved(event):
            print(f'{event["event_number"]} → {", ".join(labels)}')

Why this stays beginner-friendly

The program has two small helper functions. One converts numbers to names; the other checks the allowlist. It does not need classes, command-line frameworks, or third-party packages. The lab validator executed this code against all ten fixtures.

Go: deduplicate repeated LSASS-access alerts

What should be done

Go answer

package main

import (
    "bufio"
    "encoding/json"
    "fmt"
    "os"
    "strconv"
    "strings"
)

type Event struct {
    Number int    `json:"event_number"`
    Device string `json:"device"`
    Source string `json:"source_image"`
    Target string `json:"target_image"`
    Mask   string `json:"access_mask"`
    Signer string `json:"signer"`
}

type Approval struct{ Signer, Path string }

var approved = []Approval{
    {"Microsoft Windows Publisher", `C:\Program Files\Windows Defender Advanced Threat Protection\`},
    {"CrowdStrike, Inc.", `C:\Program Files\CrowdStrike\`},
    {"Microsoft Corporation", `C:\Program Files\Contoso\Diagnostics\`},
    {"Contoso Identity Security", `C:\Program Files\Contoso\CredentialProvider\`},
}

func isApproved(e Event) bool {
    for _, good := range approved {
        sameSigner := strings.EqualFold(e.Signer, good.Signer)
        goodPath := strings.HasPrefix(strings.ToLower(e.Source), strings.ToLower(good.Path))
        if sameSigner && goodPath { return true }
    }
    return false
}

func main() {
    file, _ := os.Open("events.jsonl")
    defer file.Close()
    seen := map[string]bool{}
    scanner := bufio.NewScanner(file)

    for scanner.Scan() {
        var e Event
        json.Unmarshal(scanner.Bytes(), &e)
        mask, _ := strconv.ParseUint(strings.TrimPrefix(e.Mask, "0x"), 16, 32)
        risky := mask & 0x007A != 0
        lsass := strings.HasSuffix(strings.ToLower(e.Target), `\lsass.exe`)
        key := strings.ToLower(e.Device + "|" + e.Source)

        if lsass && risky && !isApproved(e) && !seen[key] {
            fmt.Println(e.Number, e.Device, "→", e.Source)
            seen[key] = true
        }
    }
}

Engineering note

For a production utility, add file-open, JSON, parse, and scanner error handling plus a time-bounded cache. This lab keeps those details out so the deduplication idea stays visible. The Go source was reviewed against the fixtures but was not executed because the validation environment did not include a Go toolchain.

Honest limits
