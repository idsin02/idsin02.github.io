KQL behavior query + tuning

What should be done

  4. Keep the source URL for investigation.

Why the tuning is narrow

The exception combines repository, UID, and destination. A trusted domain alone is not enough. The CI exception also requires the runner UID and its build path.

Replace sample domains, users, and paths with owned inventory. Give every production allowlist an owner and review date.

KQL answer

This query targets the normalized custom fields shown in Day 3. Confirm your connector schema before using it.

let Window = 10m;
LinuxChainEvents_CL
| where Action_s in ("download", "chmod", "execute")
| summarize
    FirstSeen=min(TimeGenerated),
    LastSeen=max(TimeGenerated),
    Actions=make_set(Action_s),
    Downloaders=make_set_if(ProcessName_s, Action_s == "download"),
    Sources=make_set_if(SourceUrl_s, Action_s == "download"),
    Modes=make_set_if(Mode_s, Action_s == "chmod")
  by DeviceName_s, UID_d, UserName_s, NormalizedPath_s, SHA256_s
| where LastSeen - FirstSeen <= Window
| where set_has_element(Actions, "download")
  and set_has_element(Actions, "chmod")
  and set_has_element(Actions, "execute")
| where set_has_element(Downloaders, "curl") or set_has_element(Downloaders, "wget")
| where not(
    (UID_d == 0 and NormalizedPath_s startswith "/var/cache/apt/"
      and tostring(Sources) contains "https://archive.ubuntu.com/ubuntu/")
    or (UID_d == 1002 and NormalizedPath_s startswith "/builds/acme/"
      and tostring(Sources) contains "https://artifacts.acme.example/")
    or (UserName_s == "devbuild" and NormalizedPath_s startswith "/home/devbuild/src/")
)
| project FirstSeen, LastSeen, DeviceName_s, UID_d, UserName_s,
          NormalizedPath_s, SHA256_s, Sources, Modes

Analyst reasoning

Likely false positives: operating-system install scripts, approved CI runners, container image or entrypoint preparation, and developer build workflows. Verify the repository, package or job owner, UID, destination, hash, image or runner identity, and whether the execute step belongs to the same approved workflow.

CrowdStrike CQL answer

Confirm event names and parser fields with a known Linux event before using the translation.

platform="Linux" action=/^(download|chmod|execute)$/
| selfJoinFilter([aid, uid, normalized_path, sha256],
    where=[
      {action="download" process_name=/^(curl|wget)$/},
      {action="chmod" mode=/^(\+x|[0-7]*[1357][0-7]*)$/},
      {action="execute"}
    ], prefilter=true)
| groupBy([aid, uid, user_name, normalized_path, sha256],
    function=[min(@timestamp, as=first_seen), max(@timestamp, as=last_seen),
              collect([action, process_name, source_url, mode])])
| test(last_seen-first_seen <= duration("10m"))
| case {
    uid=0 normalized_path=/^\/var\/cache\/apt\// source_url=/^https:\/\/archive\.ubuntu\.com\/ubuntu\// | drop();
    uid=1002 normalized_path=/^\/builds\/acme\// source_url=/^https:\/\/artifacts\.acme\.example\// | drop();
    user_name="devbuild" normalized_path=/^\/home\/devbuild\/src\// | drop();
    *
  }

Analyst reasoning

Likely false positives: Falcon-visible package installation, CI runner bootstrap jobs, container entrypoint setup, and developer builds. Tenant schemas vary; validate the field map, wildcard behavior, time units, and parser-provided normalized_path before deployment.

Week 20 · Day 5

Python: correlate by normalized path

Page 6 / 8

What should be done

Save Day 1 data as events.jsonl. Normalize an absolute path directly; join a relative path to its working directory. Group by device, UID, normalized path, and hash, then require all three actions within ten minutes.

Easy reading plan

  1. Open one JSON object per line.
  2. Normalize the event path.
  3. Add the event to its file chain.
  4. Check actions and time.
  5. Skip only exact approved workflows.
  6. Print the two suspicious cases.

Python answer

import json
import os
from collections import defaultdict
from datetime import datetime


def normal_path(path, cwd):
    if not path.startswith("/"):
        path = os.path.join(cwd, path)
    return os.path.normpath(path)


def approved(events, path, uid, user):
    source = next((e["source_url"] for e in events if e["action"] == "download"), "")
    return (
        (uid == 0 and path.startswith("/var/cache/apt/")
         and source.startswith("https://archive.ubuntu.com/ubuntu/"))
        or (uid == 1002 and path.startswith("/builds/acme/")
            and source.startswith("https://artifacts.acme.example/"))
        or (user == "devbuild" and path.startswith("/home/devbuild/src/"))
    )


chains = defaultdict(list)
with open("events.jsonl", encoding="utf-8") as file:
    for line in file:
        event = json.loads(line)
        path = normal_path(event["path"], event["cwd"])
        key = (event["device"], event["uid"], path, event["sha256"])
        chains[key].append(event)

for (device, uid, path, sha256), events in chains.items():
    events.sort(key=lambda e: e["timestamp"])
    actions = [e["action"] for e in events]
    first = datetime.fromisoformat(events[0]["timestamp"].replace("Z", "+00:00"))
    last = datetime.fromisoformat(events[-1]["timestamp"].replace("Z", "+00:00"))
    user = events[0]["user"]

    complete = actions == ["download", "chmod", "execute"]
    in_time = (last - first).total_seconds() <= 600
    downloader = events[0]["process_name"] in {"curl", "wget"}

    if complete and in_time and downloader and not approved(events, path, uid, user):
        print(events[0]["case_id"], path, f"uid={uid}")

Week 20 · Day 6

Go: per-path mini state machine

Page 7 / 8

What should be done

Read the ordered JSONL stream. Each device + UID + normalized path + hash owns a small state. A download opens the state, chmod advances it, and execution completes it.

State transition

0 · Newwait for curl/wget
→
1 · Downloadedwait for chmod
→
2 · Executablealert if same path runs

Go answer

package main

import (
    "bufio"
    "encoding/json"
    "fmt"
    "os"
    "path/filepath"
    "strings"
    "time"
)

type Event struct {
    CaseID      string `json:"case_id"`
    Timestamp   string `json:"timestamp"`
    Device      string `json:"device"`
    User        string `json:"user"`
    Action      string `json:"action"`
    ProcessName string `json:"process_name"`
    Path        string `json:"path"`
    Cwd         string `json:"cwd"`
    SourceURL   string `json:"source_url"`
    SHA256      string `json:"sha256"`
    UID         int    `json:"uid"`
}

type State struct {
    Step int
    First time.Time
    Source, CaseID, User, Path string
    UID int
}

func normalPath(path, cwd string) string {
    if !filepath.IsAbs(path) {
        path = filepath.Join(cwd, path)
    }
    return filepath.Clean(path)
}

func approved(s State) bool {
    return (s.UID == 0 && strings.HasPrefix(s.Path, "/var/cache/apt/") &&
        strings.HasPrefix(s.Source, "https://archive.ubuntu.com/ubuntu/")) ||
        (s.UID == 1002 && strings.HasPrefix(s.Path, "/builds/acme/") &&
            strings.HasPrefix(s.Source, "https://artifacts.acme.example/")) ||
        (s.User == "devbuild" && strings.HasPrefix(s.Path, "/home/devbuild/src/"))
}

func main() {
    file, err := os.Open("events.jsonl")
    if err != nil { panic(err) }
    defer file.Close()

    states := map[string]State{}
    scanner := bufio.NewScanner(file)
    for scanner.Scan() {
        var event Event
        if err := json.Unmarshal(scanner.Bytes(), &event); err != nil {
            fmt.Fprintln(os.Stderr, "bad JSON:", err)
            continue
        }

        path := normalPath(event.Path, event.Cwd)
        key := fmt.Sprintf("%s|%d|%s|%s", event.Device, event.UID, path, event.SHA256)
        when, err := time.Parse(time.RFC3339, event.Timestamp)
        if err != nil { continue }
        state := states[key]

        switch {
        case event.Action == "download" && (event.ProcessName == "curl" || event.ProcessName == "wget"):
            states[key] = State{1, when, event.SourceURL, event.CaseID, event.User, path, event.UID}
        case event.Action == "chmod" && state.Step == 1:
            state.Step = 2
            states[key] = state
        case event.Action == "execute" && state.Step == 2:
            if when.Sub(state.First) <= 10*time.Minute && !approved(state) {
                fmt.Printf("%s %s uid=%d\n", state.CaseID, path, state.UID)
            }
            delete(states, key)
        }
    }
    if err := scanner.Err(); err != nil { panic(err) }
}

Analyst note

The state machine is intentionally small. Production code should handle out-of-order events, late arrivals, state expiry, duplicate records, process IDs, host restarts, and bounded memory. Here the goal is to understand a per-path sequence.
