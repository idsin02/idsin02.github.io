Week path

Each day adds one small piece. Day 7 combines the pieces and proves that the two suspicious series alert while five benign series stay quiet.

Detection question

For one device, process, destination, and port: are there at least six connections, is the mean interval between 30 and 900 seconds, is jitter no more than 15%, and is the pair absent from the approved baseline?

A steady rhythm is a clue, not proof. Process context and approved software ownership decide whether to alert.

Telemetry you need

  • Timestamp and device
  • Process path
  • Destination and port
  • Bytes sent per connection
  • Approved polling baseline
  • TP/TN labels for testing

Week 15 · Day 2

KQL behavior query + tuning

Page 3 / 8

Small mental model

  1. Normalize process and destination.
  2. Build one series key.
  3. Sort inside each series.
  4. Calculate adjacent intervals.
  5. Measure mean absolute deviation.
  6. Remove exact approved pairs.

Tuning choices

Six samples avoids making a decision from only two or three gaps. The 30–900 second cadence range keeps this exercise focused. The allowlist needs both process and destination; allowing either value alone would be too broad.

Replace example field names only after checking your tenant schema. Keep an owner and review date for every baseline entry.

KQL answer

Use Microsoft Defender Advanced Hunting with DeviceNetworkEvents. Live tenant validation is still required.

let MinimumSamples = 6;
let MaximumJitterPct = 15.0;
let ApprovedPolling = datatable(ProcessName:string, Destination:string)
[
  "healthcheck.exe", "health.contoso.example",
  "updater.exe", "updates.contoso.example",
  "agent.exe", "ingest.monitoring.example"
];
let Connections = DeviceNetworkEvents
| where Timestamp > ago(24h)
| where ActionType == "ConnectionSuccess"
| where RemotePort in (80, 443)
| extend ProcessName = tolower(InitiatingProcessFileName)
| extend Destination = tolower(coalesce(RemoteUrl, RemoteIP))
| extend SeriesKey = strcat(DeviceId, "|", ProcessName, "|", Destination, "|", RemotePort)
| project Timestamp, DeviceId, DeviceName, ProcessName, Destination, RemotePort, SentBytes, SeriesKey;
let Intervals = Connections
| partition hint.strategy=native by SeriesKey
(
    sort by Timestamp asc
    | serialize
    | extend PreviousTime = prev(Timestamp)
    | extend IntervalSec = datetime_diff("second", Timestamp, PreviousTime)
    | where isnotnull(PreviousTime)
);
let Means = Intervals
| summarize Samples=count() + 1, MeanIntervalSec=avg(IntervalSec)
  by SeriesKey, DeviceId, DeviceName, ProcessName, Destination, RemotePort;
Intervals
| join kind=inner Means on SeriesKey
| summarize Samples=any(Samples), MeanIntervalSec=any(MeanIntervalSec),
    MeanAbsDeviationSec=avg(abs(todouble(IntervalSec) - MeanIntervalSec)),
    FirstSeen=min(PreviousTime), LastSeen=max(Timestamp)
  by DeviceId, DeviceName, ProcessName, Destination, RemotePort
| extend JitterPct=round(100.0 * MeanAbsDeviationSec / MeanIntervalSec, 2)
| join kind=leftanti ApprovedPolling on ProcessName, Destination
| where Samples >= MinimumSamples
| where MeanIntervalSec between (30.0 .. 900.0)
| where JitterPct <= MaximumJitterPct
| project DeviceName, ProcessName, Destination, RemotePort, Samples,
    MeanIntervalSec=round(MeanIntervalSec, 1), JitterPct, FirstSeen, LastSeen
| order by JitterPct asc

Analyst reasoning

Expected false positives include health checks, update polling, monitoring agents, and collaboration applications. First ask whether the process has a documented polling purpose, whether the destination belongs to that product, and whether the cadence is stable across the approved fleet.

Week 15 · Day 3

CrowdStrike CQL translation + field map

Page 4 / 8

Translation approach

Keep the same group key and thresholds. The sample uses Falcon-style network fields, sorts each series, derives a previous timestamp, and measures interval standard deviation. Confirm function and field availability in your Falcon data before production use.

Do not compare names only

A process name may be renamed or shared by multiple products. During triage, preserve the full path, signer, device role, destination ownership, and bytes pattern even when the detection key uses a normalized name.

The CQL uses standard deviation while the browser/Python validator uses mean absolute deviation. Recalibrate 15% with your chosen statistic.

CrowdStrike CQL answer

#event_simpleName=NetworkConnectIP4
| in(field=RemotePort, values=[80, 443])
| ProcessName := lower(ImageFileName)
| Destination := lower(coalesce([RemoteDomain, RemoteAddress]))
| case {
    ProcessName="healthcheck.exe" Destination="health.contoso.example" | drop();
    ProcessName="updater.exe" Destination="updates.contoso.example" | drop();
    ProcessName="agent.exe" Destination="ingest.monitoring.example" | drop();
    *;
  }
| sort([aid, ProcessName, Destination, RemotePort, @timestamp], order=asc)
| neighbor([aid, ProcessName, Destination, RemotePort], include=[@timestamp], prefix=previous)
| IntervalSec := (@timestamp - previous.@timestamp) / 1000
| IntervalSec >= 30 IntervalSec <= 900
| groupBy([aid, ComputerName, ProcessName, Destination, RemotePort], function=[
    count(as=IntervalCount),
    avg(IntervalSec, as=MeanIntervalSec),
    stdDev(IntervalSec, as=IntervalStdDevSec),
    min(@timestamp, as=FirstSeen),
    max(@timestamp, as=LastSeen)
  ], limit=max)
| Samples := IntervalCount + 1
| JitterPct := (IntervalStdDevSec / MeanIntervalSec) * 100
| Samples >= 6 JitterPct <= 15
| sort([JitterPct, ComputerName], order=asc)

Week 15 · Day 5

Python: intervals, mean, and jitter

Page 6 / 8

Easy formula

If times are 0, 119, and 241 seconds, the intervals are 119 and 122 seconds. Their mean is 120.5. Jitter is the average distance from that mean, divided by the mean, as a percentage.

Score: 40 points for six samples + 20 for a 30–900 second mean + up to 40 for low jitter.

Run it

  2. Save the answer as beacon.py.
  3. Run python beacon.py.

Python answer

import json
from collections import defaultdict
from datetime import datetime
from statistics import fmean

MIN_SAMPLES = 6
APPROVED = {
    ("healthcheck.exe", "health.contoso.example"),
    ("updater.exe", "updates.contoso.example"),
    ("agent.exe", "ingest.monitoring.example"),
}

def process_name(path):
    return path.replace("\\", "/").split("/")[-1].lower()

def seconds(timestamp):
    return datetime.fromisoformat(timestamp.replace("Z", "+00:00")).timestamp()

def analyze(rows):
    rows.sort(key=lambda row: row["timestamp"])
    times = [seconds(row["timestamp"]) for row in rows]
    intervals = [b - a for a, b in zip(times, times[1:])]
    mean = fmean(intervals)
    jitter = fmean(abs(value - mean) for value in intervals)
    jitter_pct = 100 * jitter / mean
    score = 40 + (20 if 30 <= mean <= 900 else 0) + max(0, 40 - 2 * jitter_pct)
    first = rows[0]
    approved = (process_name(first["process_path"]), first["destination"]) in APPROVED
    match = len(rows) >= MIN_SAMPLES and score >= 70 and not approved
    return intervals, mean, jitter_pct, round(score), match

groups = defaultdict(list)
with open("connections.jsonl", encoding="utf-8") as handle:
    for line in handle:
        event = json.loads(line)
        key = (event["device"], event["process_path"], event["destination"], event["port"])
        groups[key].append(event)

for key, rows in groups.items():
    intervals, mean, jitter_pct, score, match = analyze(rows)
    if match:
        device, process, destination, port = key
        print(f"{device} | {process_name(process)} -> {destination}:{port}")
        print(f"  intervals={intervals}")
        print(f"  mean={mean:.1f}s jitter={jitter_pct:.1f}% score={score}")

Week 15 · Day 6

Go: sorted groups and interval spread

Page 7 / 8

What this version measures

Go groups the JSONL rows, sorts timestamps, then calculates the smallest and largest gap. Spread = largest gap − smallest gap. A spread no larger than 15% of the mean is a simple screening rule.

Why keep it simple

The Python and browser versions use mean absolute deviation; Go demonstrates a second, easy interval statistic. A production detector should choose one documented statistic and test it on a larger baseline.

Go was not executed in this build environment because the Go toolchain was unavailable. The source was reviewed but remains marked not run.

Go answer

package main

import (
    "bufio"
    "encoding/json"
    "fmt"
    "os"
    "sort"
    "strings"
    "time"
)

type Event struct {
    Device      string `json:"device"`
    ProcessPath string `json:"process_path"`
    Destination string `json:"destination"`
    Port        int    `json:"port"`
    Timestamp   string `json:"timestamp"`
}

type Key struct { Device, Process, Destination string; Port int }

func name(path string) string {
    parts := strings.Split(strings.ReplaceAll(path, `\`, "/"), "/")
    return strings.ToLower(parts[len(parts)-1])
}

func main() {
    approved := map[string]bool{
        "healthcheck.exe|health.contoso.example": true,
        "updater.exe|updates.contoso.example": true,
        "agent.exe|ingest.monitoring.example": true,
    }
    groups := map[Key][]time.Time{}
    file, _ := os.Open("connections.jsonl")
    defer file.Close()
    scanner := bufio.NewScanner(file)
    for scanner.Scan() {
        var event Event
        json.Unmarshal(scanner.Bytes(), &event)
        timestamp, _ := time.Parse(time.RFC3339, event.Timestamp)
        key := Key{event.Device, name(event.ProcessPath), event.Destination, event.Port}
        groups[key] = append(groups[key], timestamp)
    }
    for key, times := range groups {
        sort.Slice(times, func(i, j int) bool { return times[i].Before(times[j]) })
        if len(times) < 6 { continue }
        gaps := []float64{}
        for i := 1; i < len(times); i++ {
            gaps = append(gaps, times[i].Sub(times[i-1]).Seconds())
        }
        total, minGap, maxGap := 0.0, gaps[0], gaps[0]
        for _, gap := range gaps {
            total += gap
            if gap < minGap { minGap = gap }
            if gap > maxGap { maxGap = gap }
        }
        mean := total / float64(len(gaps))
        spread := maxGap - minGap
        spreadPct := 100 * spread / mean
        allowed := approved[key.Process+"|"+key.Destination]
        if mean >= 30 && mean <= 900 && spreadPct <= 15 && !allowed {
            fmt.Printf("%s | %s -> %s:%d | mean=%.1fs spread=%.1fs (%.1f%%)\n",
                key.Device, key.Process, key.Destination, key.Port, mean, spread, spreadPct)
        }
    }
}

Collaboration apps

Presence and notification traffic may recur. Compare jitter, process path, signed publisher, user session, and product-owned domains.

Bytes as context

Similar byte counts can strengthen a beacon hypothesis, but variable encrypted sizes do not disprove it. Bytes are not part of this teaching score.

Baseline discipline
