Week 10 Â· Day 2

KQL behavior query + tuning

Page 3 / 8

Build it in four checks

  1. Keep registry value create/set actions.
  2. Keep Run and RunOnce keys.
  3. Look for interpreters or user-writable locations.
  4. Remove only exact approved combinations.

Tuning rule

Never exclude all signed files, all AppData startup, or an entire user. Require the value name, product path, and expected signer together.

An exclusion should have an owner, scope, review date, and evidence from your environment.

KQL answer

let ScriptInterpreters = dynamic(["powershell.exe", "pwsh.exe", "wscript.exe", "cscript.exe", "mshta.exe", "cmd.exe", "python.exe"]);
DeviceRegistryEvents
| where ActionType in ("RegistryValueSet", "RegistryValueCreated")
| where RegistryKey endswith @"\Software\Microsoft\Windows\CurrentVersion\Run"
    or RegistryKey endswith @"\Software\Microsoft\Windows\CurrentVersion\RunOnce"
| extend Data = tolower(tostring(RegistryValueData)), ActorSigner = tostring(InitiatingProcessVersionInfoCompanyName)
| where Data has_any (ScriptInterpreters)
    or Data contains @"\appdata\"
    or Data contains @"\downloads\"
    or Data contains @"\temp\"
    or Data contains "%appdata%\"
    or Data contains "%localappdata%\"
    or Data contains "%temp%\"
| where not(RegistryValueName == "com.squirrel.Teams.Teams" and Data contains @"\microsoft\teams\update.exe" and ActorSigner =~ "Microsoft Corporation")
| where not(RegistryValueName == "OneDrive" and Data contains @"\microsoft\onedrive\onedrive.exe" and ActorSigner =~ "Microsoft Corporation")
| where not(RegistryValueName == "ContosoSecurityAgent" and Data contains @"\program files\contoso\security agent\agent.exe" and ActorSigner =~ "Contoso Security Ltd.")
| where not(RegistryValueName == "Discord" and Data contains @"\appdata\local\discord\update.exe" and ActorSigner =~ "Discord Inc.")
| project Timestamp, DeviceName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, InitiatingProcessCommandLine, ActorSigner, InitiatingProcessAccountName
| order by Timestamp desc

Analyst reasoning Â· false positives

Likely false positives: Microsoft Teams or OneDrive rewriting their startup entries after an update, approved security/management agents, and approved user-installed applications that use per-user AppData startup. Verify the exact value name, target path, signer, writer process, update time, software owner, and whether the command later ran. A trusted signer lowers risk; it does not make every command safe.

Easy reading plan

  1. Read one JSON object.
  2. Get registry.value_data.
  3. Find quoted or full Windows paths.

  5. Print the case and paths.

Expected examples

R1 -> ['C:\Users\mia\AppData\Roaming\cache\sync.ps1']
R2 -> ['C:\Windows\System32\wscript.exe', 'C:\Users\lee\Downloads\login.vbs']
B5 -> ['C:\Windows\System32\SecurityHealthSystray.exe']

Python answer

import json
import re

# Quoted paths or full Windows paths ending in a useful extension.
PATH = re.compile(
    r'"([^"]+\.(?:exe|com|cmd|bat|ps1|vbs|js|py))"'
    r'|((?:[A-Za-z]:\\|%[A-Za-z_]+%\\)[^"]*?\.(?:exe|com|cmd|bat|ps1|vbs|js|py))',
    re.IGNORECASE,
)
BARE_INTERPRETER = re.compile(
    r'(?i)(?:^|\s)(powershell|pwsh|wscript|cscript|mshta|cmd|python)\.exe\b'
)

def extract_paths(command):
    paths = []
    for match in PATH.finditer(command):
        paths.append(match.group(1) or match.group(2))
    if not paths:
        bare = BARE_INTERPRETER.search(command)
        if bare:
            paths.append(bare.group(0).strip())
    return paths

with open("events.jsonl", encoding="utf-8") as source:
    for line in source:
        event = json.loads(line)
        data = event["registry"]["value_data"]
        print(event["case_id"], "->", extract_paths(data))

Why extraction matters

The first executable may be a trusted interpreter while the second path is the suspicious script. Keep every extracted path; do not stop after powershell.exe or wscript.exe.

Go answer

package main

import (
    "fmt"
    "strings"
)

func normalize(path string) string {
    path = strings.TrimSpace(path)
    path = strings.Trim(path, "\"'")
    path = strings.ReplaceAll(path, "/", "\\")
    return strings.ToLower(path)
}

func classify(path string) string {
    p := normalize(path)
    switch {
    case strings.Contains(p, "\\appdata\\") || strings.HasPrefix(p, "%appdata%\\") || strings.HasPrefix(p, "%localappdata%\\"):
        return "user-writable: AppData"
    case strings.Contains(p, "\\downloads\\"):
        return "user-writable: Downloads"
    case strings.Contains(p, "\\temp\\") || strings.HasPrefix(p, "%temp%\\"):
        return "user-writable: Temp"
    case strings.HasPrefix(p, "c:\\windows\\"):
        return "system location"
    case strings.HasPrefix(p, "c:\\program files\\"):
        return "installed application"
    default:
        return "review"
    }
}

func main() {
    tests := []string{
        `"C:\Users\mia\AppData\Roaming\cache\sync.ps1"`,
        `C:/Users/lee/Downloads/login.vbs`,
        `%TEMP%\svchost.exe`,
        `"C:\Windows\System32\wscript.exe"`,
        `"C:\Program Files\Contoso\Security Agent\agent.exe"`,
    }
    for _, path := range tests {
        fmt.Printf("%-68s -> %s\n", normalize(path), classify(path))
    }
}

Final hunt checklist

  1. Confirm the value was newly created or changed.
  2. Review writer process, signer, user, and device.
  3. Parse the command and inspect every referenced path.
  4. Find the related process start at logon.
  5. Apply only an exact approved exclusion.
  6. Record outcome, evidence, owner, and tuning decision.
